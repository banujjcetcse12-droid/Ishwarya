# Hotel Management System

A simple Hotel Management System project developed using HTML, CSS, and JavaScript.

## Features

- View available rooms
- Book hotel rooms
- Simple and clean user interface
- Customer room booking system
- Local storage support

## Technologies Used

- HTML
- CSS
- JavaScript
- VS Code

## Project Structure

HotelManagementSystem/
│
├── index.html
├── rooms.html
├── booking.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone the project
2. Open the project folder in VS Code
3. Open `index.html`
4. Run using Live Server
